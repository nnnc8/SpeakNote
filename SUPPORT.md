# SpeakNote support

## Choose the right channel

- **How-to questions and ideas:**
  [GitHub Discussions](https://github.com/nnnc8/SpeakNote/discussions)
- **Reproducible bugs:**
  [GitHub Issues](https://github.com/nnnc8/SpeakNote/issues)
- **Sensitive vulnerabilities:** follow [SECURITY.md](SECURITY.md); do not post
  security details publicly
- **Privacy information:** read the [privacy notice](docs/privacy/index.md)

## Before reporting a bug

Check that you are using macOS 14 or later and note whether the app came from a
GitHub Release or was built from source. Search existing Issues, then include:

- SpeakNote source version, release version, or commit;
- macOS version and Apple silicon or Intel;
- selected transcription provider and whether local-only mode is enabled;
- exact steps, expected result, and actual result;
- non-sensitive screenshots when useful;
- whether retrying, relaunching, or changing the relevant permission helped.

Never attach credentials, recordings, recognized content, prompts, cloud
responses, system logs containing personal data, or private filesystem paths.

## No guaranteed SLA

SpeakNote is an open-source project without a guaranteed support response time.
Clear, minimal reproductions are the fastest route to a useful answer.

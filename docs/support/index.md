# SpeakNote support

## Questions and ideas

Use [GitHub Discussions](https://github.com/nnnc8/SpeakNote/discussions) for
setup questions, usage help, and feature ideas. Search existing topics first.

## Bug reports

Use [GitHub Issues](https://github.com/nnnc8/SpeakNote/issues) for a reproducible
bug. Include:

- SpeakNote source version, release version, or commit;
- macOS version and Apple silicon or Intel;
- selected provider and whether local-only mode is enabled;
- exact steps, expected result, and actual result;
- whether the relevant macOS permission is granted;
- a non-sensitive screenshot when it helps.

Do not attach credentials, recordings, recognized content, provider responses,
personal system logs, or private filesystem paths.

## Security and privacy

Do not publish vulnerability details in an Issue or Discussion. Follow the
[security policy](https://github.com/nnnc8/SpeakNote/blob/main/SECURITY.md).
For data-flow details, read the [privacy notice]({{ '/privacy/' | relative_url }}).

## Release status

The source version is v0.1.0. Check
[GitHub Releases](https://github.com/nnnc8/SpeakNote/releases/latest) for an
actual downloadable asset and its signing and notarization statement. Source
availability alone does not establish that a public binary has been released.

SpeakNote is an open-source project and does not offer a guaranteed support SLA.
